# techquiz

A full-stack web application that lets users test their technical knowledge through an interactive quiz. Built with React, Node.js, TypeScript, and Cypress for end-to-end testing.
walkthrough video: https://app.screencastify.com/v3/watch/OnTpC3E689Cml96jPPMA 

---

## Features

-  Start a timed or untimed quiz
-  Multiple-choice questions from a backend API
-  Score tracking and feedback
-  Option to restart the quiz
-  End-to-end and component testing with Cypress

- **Backend**: Node.js + Express
